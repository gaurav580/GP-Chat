# GP Chat 🔱🤖

GP Chat is an AI-powered chat web application built using Flask and JavaScript.
It focuses on clean UI, security, and real-world deployment practices.

## Features
- AI-powered chat responses
- Secure API key handling using `.env`
- Flask backend
- JavaScript frontend
- PWA-ready structure

## Tech Stack
- Python (Flask)
- HTML, CSS, JavaScript
- OpenRouter API
- Git & GitHub

## Local Setup
```bash
git clone https://github.com/gaurav580/GP-Chat.git
cd GP-Chat
pip install -r requirements.txt
python app.py
